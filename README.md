# Record Application

It is basically Champion list. In which it shows the details of the champion's character by calling the data from the API with the help of a ktor 
and clean architecture has been used in it for detail integration.
In other words League of Legends strategy guide and record keeper."

## Key Features:
* Easy navigation and intuitive interface
* Clean and modern UI design
* Real time Search
* shows Champions details and abilities
  
## Technical Requirements:
 * Kotlin + Jetpack Compose
 * API calling using Ktor
 * Dependency injection with Hilt
 * MVVM Architecture
